# Провод — чат на Google-таблице

Простой мессенджер: сообщения синхронизируются через вашу Google-таблицу. Своего сервера поднимать не нужно — роль бэкенда играет Google Apps Script. Клиент (`index.html`) — статическая страница, её можно положить прямо на **GitHub Pages**.

## Как это работает

- Оба собеседника вводят одно кодовое слово → попадают в общую «комнату».
- Слово хешируется в идентификатор комнаты (само слово никуда не отправляется).
- Сообщения пишутся в таблицу и подтягиваются раз в ~2 секунды.

## Что важно понимать

- Сообщения хранятся в таблице — это не end-to-end шифрование. Подходит для рабочих и дружеских чатов.
- «Онлайн» здесь — опрос раз в пару секунд, а не мгновенный push.

## Настройка (если ещё не сделана)

1. Создайте Google-таблицу → **Расширения → Apps Script**.
2. Вставьте код из `Code.gs`, сохраните.
3. **Deploy → New deployment → тип Web app**, доступ **Anyone**, Deploy.
4. Скопируйте Web app URL (заканчивается на `/exec`) и вставьте в `index.html` в строку `SHEET_API_URL`.

> В этом файле URL уже вписан — если таблица та же, ничего менять не нужно.

## Публикация на GitHub Pages

1. Создайте на GitHub новый репозиторий (например, `provod`).
2. Загрузите в него файлы (см. команды ниже или через кнопку **Add file → Upload files** на сайте GitHub).
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save**.
4. Через минуту появится адрес вида `https://ваш-логин.github.io/provod/` — это и есть ваш работающий мессенджер.

### Загрузка через командную строку

```bash
cd provod-final
git init
git add .
git commit -m "Провод — чат на Google Sheets"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/provod.git
git push -u origin main
```
