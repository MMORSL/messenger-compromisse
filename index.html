Отсканируйте камерой телефона — откроется тот же «Провод».

Страница открыта локально — этот адрес недоступен с других устройств. Разместите файл на бесплатном хостинге (например Netlify Drop или GitHub Pages), чтобы QR-код заработал.

Придумайте кодовое слово и сообщите его собеседнику любым способом — голосом, в другом чате, лично. Оба введите одно и то же слово и нажмите кнопку — соединение произойдёт само.

Кодовое слово
Как это устроено: слово превращается в общий идентификатор, по которому вас с собеседником сводит открытый брокер-сервис (PeerJS). Через него проходит только само «рукопожатие» — переписка после соединения идёт напрямую между браузерами.
